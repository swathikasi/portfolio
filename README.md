# Swathika K — Portfolio

## Easiest: just open the page (no install)
Open `public/index.html` in your browser (or in VS Code: right-click > Open with Live Server).
The contact form opens your email app when no backend is running.

## With backend (Python, no pip install)
In the VS Code terminal (Ctrl + `):
    python server.py
(on Mac/Linux: python3 server.py)
It opens http://localhost:8000. Contact messages are saved in `data/messages.json`.

## Edit content
Change text, projects, skills in `public/profile.js`.

## Files
server.py           Python backend
public/             index.html, style.css, script.js, profile.js
data/messages.json  Saved contact messages
